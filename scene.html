SCENE의 주요 기능

스캔 원시 데이터를 실제 업무에 활용할 수 있는 정합된 포인트 클라우드 데이터로 전환합니다.

01

Point Cloud Registration

서로 다른 위치에서 취득한 여러 스캔 데이터를 하나의 좌표계와 공간으로 정합합니다.

02

3D Visualization

정합된 포인트 클라우드를 3D 환경에서 확인하고 현장의 구조와 공간 상태를 검토할 수 있습니다.

03

Quality Control

스캔 누락 구간과 정합 상태를 확인하여 데이터의 완성도와 품질을 검토할 수 있습니다.

04

Project Management

대규모 스캔 데이터를 프로젝트 단위로 구성하고 후속 분석과 모델링 업무에 활용할 수 있도록 관리합니다.

APPLICATIONS

활용 업무

건설·플랜트·시설 관리 등 다양한 분야에서 현장 스캔 데이터를 검토하고 활용하는 데 사용됩니다.

Scan Registration

건설 현장이나 대규모 시설에서 여러 위치로 나누어 취득한 스캔 데이터를 하나의 공간으로 정합합니다.

Site Review

실제 현장을 다시 방문하지 않고도 3D 데이터에서 구조와 치수, 공간 상태를 검토할 수 있습니다.

As-Built Preparation

CAD·BIM 기반 현황 모델링에 필요한 정합된 포인트 클라우드 데이터를 준비합니다.

Facility Management

플랜트와 산업 시설의 현황 데이터를 기록하고 유지보수 및 개보수 검토에 활용합니다.

Digital Twin

실제 공간의 3D 데이터를 디지털 환경에 구축하여 디지털 트윈 프로젝트의 기초 자료로 활용합니다.

Data Sharing

SCENE에서 정합한 현장 데이터를 Sphere WebShare 또는 SCENE 2go로 공유하여 설계·시공·품질관리 관계자가 동일한 기준으로 검토할 수 있도록 지원합니다.
