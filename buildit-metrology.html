WHY BUILDIT METROLOGY

검사 결과를 실제 제조 공정으로 연결합니다.

CAM2가 측정과 품질 검사에 집중한다면, BuildIT Metrology는 측정 결과를 활용해 조립·정렬·자동화 작업까지 지원합니다.

CAM2

측정 및 검사

측정 데이터를 수집하고 CAD 비교, 치수 검사와 GD&T 판정을 수행합니다.

BuildIT

조립 및 정렬

측정 결과를 이용해 부품을 정확한 위치로 이동시키고 실제 조립과 정렬 작업을 실시간으로 안내합니다.

Process

반복 공정 자동화

측정, 판정, 작업 안내와 보고서 작성 과정을 반복 가능한 워크플로우로 구성합니다.

Result

생산 품질 향상

조립 단계에서 오차를 조기에 확인하여 재작업과 폐기물을 줄이고 생산 효율을 높입니다.

PRODUCT HIGHLIGHTS

BuildIT Metrology의 주요 기능

제조 현장의 실시간 측정과 조립부터 검사 자동화와 품질 보고까지 하나의 플랫폼에서 수행합니다.

01

Assembly Guidance

모든 축의 3D 위치 편차를 실시간으로 표시하고, 작업자가 부품을 정확한 위치로 이동할 수 있도록 시각적인 방향 정보를 제공합니다.

02

Precision Alignment

Laser Tracker와 FaroArm 등의 측정 데이터를 활용해 대형 부품, 설비 및 조립체의 위치와 정렬 상태를 정밀하게 조정합니다.

03

CAD Validation

단일 포인트 또는 포인트 클라우드 데이터를 CAD 설계 모델과 비교하여 표면 편차와 기하학적 특성을 검증합니다.

04

GD&T Evaluation

CAD에 포함된 GD&T, FTA 및 NX-PMI 데이터를 불러와 측정 과정에서 공차를 자동으로 평가하고 ASME와 ISO 기준에 따른 검사를 지원합니다.

05

Configurable Automation

작업 과정을 기록하여 반복 가능한 프로세스를 만들고, 조건문, 변수, 호출 프로세스와 Python 확장을 활용해 복잡한 제조 워크플로우도 자동화할 수 있습니다.

06

Custom Reporting

검사 결과를 차트, 그래프, 스크린샷과 데이터 표로 구성하고 PDF, XLSX 및 CSV 형식으로 내보낼 수 있습니다.

HARDWARE COMPATIBILITY

다양한 측정 장비와 제조 시스템을 연결합니다.

BuildIT Metrology는 FARO 측정 장비뿐 아니라 타사 계측 하드웨어와 로봇 시스템도 연계할 수 있습니다.

FaroArm

중소형 부품과 조립체의 접촉식 측정, 레이저 스캐닝 및 현장 품질 검사에 활용합니다.

Vantage Laser Tracker

대형 구조물과 생산 설비의 위치 측정, 정밀 조립 및 정렬 작업에 활용합니다.

6Probe

Laser Tracker의 측정 범위에서 접근하기 어려운 위치를 핸드헬드 방식으로 측정합니다.

Tracer Laser Projector

조립체와 공장 배치 작업을 위한 설계 템플릿과 위치 정보를 실제 작업면에 투영합니다.

Robotic Systems

입력·출력 인터페이스를 통해 외부 로봇과 연결하여 자동화된 측정 및 제조 공정을 구성합니다.

Third-Party Hardware

프로젝트 환경에 따라 다양한 타사 계측 하드웨어와 함께 사용할 수 있습니다.

CAD & AUTOMATION

설계 검증과 반복 제조 공정을 하나의 환경에서 관리합니다.

CAD 데이터를 기반으로 측정 결과를 평가하고, 사용자 작업 절차에 맞는 자동화 프로세스를 구성할 수 있습니다.

01

CAD Data Import

CATIA, NX, Parasolid, Creo, Inventor, SolidWorks, AutoCAD와 IGES, STEP, SAT, JT 등 주요 CAD 형식을 불러옵니다.

02

Surface Deviation Analysis

단일 측정 포인트 또는 포인트 클라우드를 CAD 모델과 비교하여 표면 편차를 분석합니다.

03

Model-Based GD&T

CAD에 포함된 GD&T, FTA 및 NX-PMI 데이터를 가져와 측정 과정에서 공차를 자동으로 평가합니다.

04

No-Code Process Recording

별도의 코딩 없이 작업 과정을 기록해 작업자 안내와 반복 가능한 검사 프로세스를 구성합니다.

05

Advanced Logic

조건문, 변수와 하위 프로세스를 이용해 복잡한 검사 및 제조 공정을 구성할 수 있습니다.

06

Python Extension

Python 확장 기능으로 기업별 제조 환경에 필요한 고급 자동화와 사용자 정의 기능을 추가할 수 있습니다.
