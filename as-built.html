PRODUCT HIGHLIGHTS

As-Built의 주요 기능

정합된 포인트 클라우드 데이터를 도면과 모델로 전환해 설계·검토·문서화 업무에 활용합니다.

01

Point Cloud to CAD

포인트 클라우드 데이터를 CAD 환경으로 불러와 기존 구조물과 설비를 도면화할 수 있습니다.

02

2D Documentation

실제 현장 데이터를 기반으로 평면도, 입면도, 단면도 등 2D 문서를 작성할 수 있습니다.

03

3D Modeling

건축물, 플랜트, 배관 및 설비의 실제 형상을 3D 현황 모델로 구축할 수 있습니다.

04

Design Review

기존 현황과 계획된 설계안을 함께 검토하여 간섭과 변경 필요 지점을 사전에 확인할 수 있습니다.

APPLICATIONS

활용 업무

실제 현장 상태를 기반으로 한 설계와 문서화가 필요한 다양한 프로젝트에 활용할 수 있습니다.

As-Built Documentation

기존 건축물과 산업 시설의 실제 시공 상태를 도면과 3D 모델로 기록합니다.

Renovation & Retrofit

리모델링, 증설, 개보수 프로젝트의 설계 기초 자료와 현황 모델을 구축합니다.

Plant & MEP

플랜트 배관, 기계, 전기 설비 등의 실제 위치와 형상을 모델링하고 문서화합니다.

BIM Modeling

스캔 데이터를 기반으로 기존 시설의 BIM 모델 생성과 검토 업무를 지원합니다.

Design Coordination

실제 현황과 신규 설계안을 비교하여 간섭과 공간 제약을 사전에 검토합니다.

Facility Management

시설 유지보수와 자산 관리를 위한 현황 도면과 3D 모델을 구축합니다.
