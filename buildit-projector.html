도면을 보면서 위치를 재는 대신, 부품을 놓아야 할 위치를 실제 작업면에 직접 표시합니다.

BuildIT Projector는 3D CAD 모델을 기반으로 부품의 외곽선, 기준점, 문자와 화살표 등을 실제 작업 대상에 레이저로 투영하도록 레이저 프로젝터를 제어하는 소프트웨어입니다.

작업자는 투영된 레이저 선에 맞춰 부품을 배치하고, 정해진 순서에 따라 조립 작업을 수행할 수 있습니다. 작업 중이나 조립 완료 후에는 카메라 이미지를 이용해 부품의 위치와 유무, 작업 오류 및 이물질을 검증할 수 있습니다.

WHY BUILDIT PROJECTOR

물리적 템플릿 없이 작업 위치와 순서를 안내합니다.

CAD 기반의 디지털 레이저 템플릿을 사용해 작업 준비와 부품 배치를 단순화하고, 조립 과정에서 발생하는 위치 오류와 누락을 줄일 수 있습니다.

01

Physical Template Reduction

부품별 물리적 템플릿과 치공구를 별도로 제작하고 보관·수정하는 작업을 줄일 수 있습니다.

02

Repeatable Work Guidance

작업자에게 동일한 순서와 위치 정보를 제공해 경험 수준에 따른 작업 결과의 차이를 줄입니다.

03

In-Process Quality Control

조립이 모두 끝난 후에만 검사하지 않고, 각 작업 단계에서 부품 배치와 유무를 확인합니다.

04

Scrap & Rework Reduction

위치 오류, 부품 누락과 이물질을 조기에 발견해 폐기와 재작업 가능성을 줄입니다.

SOFTWARE COMPONENTS

작업 설계와 현장 실행을 분리해 관리합니다.

제조 엔지니어는 작업 워크플로우를 설계하고, 현장 작업자는 준비된 절차를 따라 작업을 실행합니다.

PLANNER

BuildIT Projector Planner

제조 엔지니어가 레이저 템플레이팅과 검증 절차를 설정합니다. 투영 순서, 부품 배치, 작업 단계와 검증 조건을 구성할 수 있습니다.

OPERATOR

BuildIT Projector Operator

현장 작업자가 Planner에서 준비한 워크플로우를 실행합니다. 레이저 안내에 따라 부품을 배치하고 단계별 검증을 수행합니다.

CORE CAPABILITIES

레이저 투영부터 조립 검증까지 지원합니다.

CAD 데이터를 이용해 작업 정보를 생성하고, 레이저 프로젝터와 이미징 기능을 활용해 작업 실행과 품질 검증을 연결합니다.

01

Design Data Validation

CATIA, NX, Creo, Inventor, SolidWorks, AutoCAD 등 네이티브 CAD와 IGES, STEP, SAT, JT 등의 중립 형식을 불러와 투영 계획을 생성합니다.

02

Laser-Assisted Assembly

부품의 외곽선을 작업면에 레이저로 투영하고, 실제 부품의 모서리가 레이저 선과 일치하도록 위치를 조정합니다.

03

In-Process Verification

작업 단계별 또는 조립 완료 후 부품의 존재 여부와 위치를 CAD 데이터 또는 기준 이미지와 비교하여 검증합니다.

04

Foreign Object Debris Detection

공구, 너트, 볼트, 미사용 부품과 용접 부산물처럼 작업면에 남아 있는 이물질을 이미지로 확인합니다.

05

Feature-Based Alignment

CAD 모델에서 구멍이나 모서리 같은 정렬점을 지정해 외부 카메라나 반사 타겟 없이 빠르게 작업 대상과 투영 데이터를 정렬합니다.

06

Projector Operation Interface

단일 프로젝터 또는 여러 프로젝터를 제어하여 설계 템플릿, 설비 위치, 문자, 십자선과 방향 화살표 등을 투영합니다.

WHEN TO CHOOSE

다음과 같은 작업 환경에 적합합니다.

작업 위치를 반복적으로 표시하거나, 물리적 템플릿을 사용하기 어렵고 조립 단계별 검증이 필요한 공정에 활용할 수 있습니다.

01

부품 위치를 정확히 안내해야 할 때

대형 작업면이나 복잡한 형상 위에 부품의 배치 위치를 직접 표시해야 하는 경우에 적합합니다.

02

작업 순서를 표준화해야 할 때

여러 작업자가 동일한 절차와 기준으로 조립 작업을 수행하도록 안내할 수 있습니다.

03

물리적 템플릿 관리가 부담될 때

제품 종류나 설계 변경이 많아 하드 템플릿을 반복 제작하고 보관하기 어려운 환경에 적합합니다.

04

작업 중 품질 검증이 필요할 때

조립이 완료되기 전에 위치 오류, 부품 누락과 이물질을 확인해야 하는 공정에 활용합니다.

APPLICATIONS

활용 업무

정밀한 위치 안내와 반복 가능한 조립 절차가 필요한 제조 및 건설 작업에 활용합니다.

Assembly Alignment

부품의 외곽선과 기준점을 투영해 목표 위치에 맞게 부품을 배치하고 조립합니다.

In-Process Verification

작업 단계별로 부품의 위치와 유무를 검사해 조립 오류를 조기에 확인합니다.

FOD Inspection

공구, 볼트, 잔여 부품과 용접 부산물 등 작업면의 이물질을 검토합니다.

Paint & Decal Templating

도장 경계, 로고와 데칼 위치를 작업면에 투영해 마킹과 부착 작업을 안내합니다.

Composites & Ply Lay-Up

복합재 적층 공정에서 각 소재의 위치와 적층 순서를 레이저로 안내합니다.

Prefabrication & Construction

프리패브 부품의 제작 위치, 건축 요소와 설비 배치 기준을 투영합니다.
